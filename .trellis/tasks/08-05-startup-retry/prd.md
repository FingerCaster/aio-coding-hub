# 启动失败可重试

## Goal

应用启动的瞬时初始化失败可以由用户重试恢复，且前端不会因监听/快照竞态显示旧状态。

## Requirements

- Rust 只缓存成功 DB，失败后下次调用重新初始化。
- 并发成功初始化仍只执行一次。
- 前端先监听后取快照，并忽略过期订阅/快照结果。
- 重试能重新进入初始化并推进启动阶段。

## Acceptance Criteria

- [x] Rust 测试覆盖失败后成功和并发只初始化一次。
- [x] 前端测试覆盖监听与快照反序完成、卸载和重试。
- [x] 正常启动行为不回归。

## Out Of Scope

- 新启动 UI、数据库格式变更或后台自动无限重试。
