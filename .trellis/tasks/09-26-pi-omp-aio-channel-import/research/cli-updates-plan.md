# Pi / OMP 主动安装与升级（用户已批准）

用户于 2026-09-27 明确批准：自动检查新版本、下载安装、一键升级，但禁止自动升级。此批准扩展原任务的手动指引范围。

## 需求与验收

- 打开 Pi / OMP 管理页自动查询官方最新稳定版本；刷新及定时检查只读，不下载程序、不启动包管理器。
- 展示当前版本、最新版本、安装方式；未安装提供下载安装，旧版本提供升级。版本未知不得误报已是最新。
- 用户点击后确认名称、目标版本、安装路径；只有确认触发写入。取消、切换页面、检查失败不得触发升级。
- 保持当前安装方式和路径；不认识的脚本/包管理器明确提示手动处理，不隐式新增另一套安装。
- 成功刷新本机版本；失败提供可读原因。并发升级互斥，既有配置、凭证和供应商保持原样。

## 设计

- 复用 cli_update 的受限 HTTP、进程输出和版本查询机制，新增原生 CLI 检查/执行命令与专用版本卡片；Claude/Codex/Gemini 的接口保持兼容。
- 检查生成短期、一次性后端安装计划。执行只接收计划 ID，固定已确认版本、安装方式、目录；执行前复核当前安装，拒绝失效计划。
- Pi npm 与 Bun 包安装沿用已识别 prefix/root。Pi 首装使用用户级 npm 目录；OMP 首装或独立版升级下载固定官方 Release 资产，校验 SHA256SUMS、版本后原子替换。
- 独立版不运行远端安装脚本，不修改原生配置；Windows 可维护用户 PATH，Unix 提示安装目录 PATH。
- 官方 npm 元数据查询（2026-09-27）返回 Pi 0.87.1 / OMP 18.3.2。OMP GitHub Release v18.3.2 有各平台独立二进制与 SHA256SUMS.txt。公开 GitHub API 实测限流，使用 npm 最新稳定版本和固定 Release 校验清单，避免依赖 API 配额。
