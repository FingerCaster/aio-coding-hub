# OMP CLI 原生设置与 Agent 配置管理

## 授权与目标

用户于 2026-09-27 明确要求“OMP 的 cli 管理页需要支持 OMP 的一些配置设置，比如默认模型、各种 agent 配置等等，自行建立任务并开始”。这同时授权建任务、调研、实施与本地验证；无需重复请求方案批准。沿用当前分支，不提交前序混合改动，不发布、不改写用户真实 OMP 配置。

## 功能要求

- OMP CLI 页提供原生配置区域，延续现有卡片、表单、按钮与目标目录选择方式。
- 默认模型、思考等级、内置/自定义模型角色可以选择并保存；模型选项包含当前 models.yml 中的原生供应商与已发布 AIO 聚合入口。已有未知模型值保留，并支持手动输入。
- Agent 页列出 OMP 内置与当前目标目录中的自定义 Agent；配置启用状态、模型覆盖（含角色/思考后缀）、prewalk、advisor 等。支持创建和编辑原生自定义 Agent 的说明、工具、模型及系统提示词。
- 支持常用子任务并发、递归、努力上限、隔离以及会话压缩设置。下拉/开关优先，数值必须校验，未配置值可恢复继承。
- 设置操作明确作用于所选全局/Profile 目录；项目、CLI 参数、环境变量及运行中会话的覆盖关系必须说明。
- 自动检查版本但不自动升级的既有行为保持不变。

## 验收

1. 正确读写 OMP 18.3.2 原生字段；真实 OMP 在隔离临时目录能读取所保存配置。
2. 不修改凭证、会话、项目配置及 models.yml；未编辑字段语义保留，保存原文备份。
3. 外部编辑、切换目标、文件优先级变化均拒绝陈旧保存；损坏、超大、重复键、特殊 YAML 与链接目标不能被覆盖。
4. Agent 配置覆盖与自定义文件读写遵从原生路径和语义；未知扩展字段、提示词及已有自定义值保留。
5. 前端交互和后端文件边界测试通过；检查 TS、Lint、Rust fmt/Clippy、生成绑定、构建和文档链接。

## 范围

本次管理持久化原生配置，不充当 OMP 运行中 Agent 的监控/对话控制台。插件/项目 Agent 仍由对应来源管理；本页不加载或执行插件。Pi 设置页不在本次范围。MSI 打包留待用户要求。

## 用户验收反馈：继承模型可见性

- 用户反馈角色下拉只显示“继承原生”，无法知道具体模型；授权直接修复。
- 在不写入配置的前提下展示当前草稿可解析的具体模型和继承路径，支持角色别名、思考后缀和 Agent 定义。
- 无固定模型、候选回退、父会话和认证相关的运行时选择需说明原因，不把目录第一项冒充实际模型。
- 默认模型修改或恢复继承后立即更新相关角色预览；预览不能产生保存补丁。
