# 路由草稿默认当前模式

## Goal

Provider 调用顺序编辑器首次打开时与该 CLI 当前已激活模式一致，同时不覆盖用户在查询加载期间做出的选择。

## Requirements

- 路由草稿按 CLI 独立初始化一次。
- 已激活模式仍存在时选择该模式；不存在或未激活时选择默认顺序。
- 显式选择立即锁定本次初始化结果。

## Acceptance Criteria

- [x] 当前模式存在时，草稿选择和成员来自该模式。
- [x] 查询分阶段完成时不覆盖显式选择。
- [x] 切换 CLI 后新 CLI 独立初始化。

## Out Of Scope

- Provider 启停语义、运行时路由和任何新 UI 控件。
