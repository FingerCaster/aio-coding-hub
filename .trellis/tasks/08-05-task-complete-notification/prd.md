# 任务完成通知可靠性

## Goal

避免请求仍在运行或旧计时器失效后误发任务完成通知。

## Requirements

- 每个 CLI 的通知计时器绑定请求活动世代。
- 触发前复核前端状态与后端活动请求快照。
- 同 CLI 后端仍活跃、快照失败或世代变化时不通知。
- 保持所有 CLI 现有默认 30 秒静默期。

## Acceptance Criteria

- [x] 测试覆盖正常通知、重叠请求、后端仍活跃、快照失败和旧计时器。
- [x] 现有通知开关、声音和会话归属逻辑不回归。
- [x] Codex 仍使用默认静默期，不引入额外延迟。

## Out Of Scope

- 通知 UI、静默期配置项或 CLI 特殊静默期。
